CIH Portable Linux native và Docker

Báo cáo hậu kiểm sau khi sửa năm lỗi CIH Portable đã xác nhận trong nghiên cứu ban đầu. Cùng một bundle release được chạy native và đóng vào OCI: warm index đã hoạt động lại, graph report vượt safety gate, tài liệu serve an toàn có thể copy/paste, MCP smoke chạy với mawk, và port 8080 bận chỉ còn là cảnh báo.

Executive summary

Kết quả: toàn bộ năm bug hiện tại trong báo cáo gốc đã được sửa và có regression evidence. OCI có Git, fresh-container warm index skip analyze/discover 3/3; full self-index có 0 duplicate node, 0 duplicate edge và tạo RegistryGraphReport hợp lệ. Safety gate RegistryGraphReport::try_build không bị nới lỏng.

Chọn Linux native khi

Developer workstation/CI runner Linux x86_64 có glibc ≥ 2.28; cần no-op nhanh, source path tự nhiên và ít lớp debug.

Sau fix Warm --no-wiki median 0,028 s.

Chọn Docker khi

Host là musl/Alpine, cần isolation, image pinning, UID/network/mount policy hoặc deploy theo container. Git hiện là runtime guarantee của image.

Sau fix Warm fresh-container median 0,228 s; graph parity tuyệt đối.

Trade-off còn lại

Git và dependency runtime làm image tăng 30,07 MB (+51,6%). Bind mount vẫn cần UID/GID phù hợp; index và serve vẫn phải dùng cùng container path.

Design / operations Không còn bug mở trong phạm vi năm lỗi.

Bug register

Trạng thái cập nhật theo working patch; mỗi bug chỉ chuyển sang fixed khi regression evidence tương ứng đã pass.

MEDIUMĐã sửa + OCI regression

DOCK-GIT-001 · Stock OCI mất warm-index cache

Fix: Dockerfile.portable cài git với --no-install-recommends; workflow kiểm tra executable, package/SBOM, HEAD, named volume và host-UID bind.

Evidence: Git 2.39.5; fresh-container warm 0,216–0,231 s, skip analyze/discover 3/3; last_git_head=b49fc9e…. Image tăng 30.070.119 B. Không thêm SSH client, clone feature hay safe.directory=*.

MEDIUMĐã sửa + self-index gate

GRAPH-DUP-002 · Graph identity làm mất quality metadata

Fix tại nguồn: DI XML tái dùng NodeId của type đã parse; Rust external impl tạo đúng một owner placeholder; DB-access deduplicate identity của query→table nhưng giữ từng caller→query.

Evidence: regression cho source/external bean, enum/record, repeated SQL use và Rust external impl đều pass; full self-index có 0 duplicate node/edge, 1 AuditQueue, graph report schema v1. Safety gate CRITICAL RegistryGraphReport::try_build không đổi.

MEDIUMĐã sửa + live smoke

DOC-OCI-003 · Docker serve example thiếu auth

Fix: docs tách secure MCP/API và local Graph UI; cả hai publish host loopback, secure dùng token/Bearer/TLS guidance, local dùng explicit CIH_ALLOW_INSECURE=1.

Evidence: secure `/graph` + `/mcp` trả 401 không token và 200 có token; local `/graph` 200; Docker inspect xác nhận 127.0.0.1.

LOWĐã sửa + mawk smoke

SMOKE-MAWK-004 · Smoke script phụ thuộc gawk

Fix: smoke.sh dùng POSIX tolower($1), loại CR và tự probe mixed-case header trước suite.

Evidence: exact parser và full portable smoke đều pass dưới mawk 1.3.4, gồm MCP initialize, tools/list, search, query và communities. gawk không có trên host nên không chạy cục bộ.

LOWĐã sửa + process test

DOCTOR-PORT-005 · Port 8080 bận làm doctor exit 1

Fix: JSON check có trường additive blocking; port mặc định là advisory, các check home/registry/runtime/graph/repository vẫn blocking.

Evidence: listener thật trên 127.0.0.1:8080: exit 0, top-level ok=true, port.ok=false, port.blocking=false, human output WARN. CIH_HOME read-only vẫn exit 1.

HIGHĐã sửa + regression pass

PORT-CSV-006 · Ladybug COPY CALLS vỡ với nested JSON

Lịch sử trước 6545e26: CSV CALLS có JSON chứa comma/quote/newline làm loader báo sai số cột và dừng publication.

Fix: commit 6545e26 cố định CSV dialect và thêm contract copy_round_trips_late_nested_call_sites_and_quoted_fields. 5 contract tests pass; 6 full-repo run không có COPY CALLS hay content digest mismatch. Đây là bug lịch sử, không phải bug HEAD.

Giới hạn thiết kế, không phân loại bug

  • Repo được định danh bằng canonical absolute path; index và serve phải thấy cùng path, đặc biệt qua container recreate.
  • Index cần ghi cả /repo/.cih và CIH_HOME; read-only mount không được hỗ trợ cho index.
  • UID 1001 mặc định phù hợp named volume đã chown, không tự tương thích mọi host bind mount.
  • Portable native cần glibc ≥ 2.28 và không chạy native trên musl; OCI là đường hỗ trợ thay thế.

Không còn bug mở trong scope: không có crash, data loss, auth bypass, graph divergence, duplicate identity, COPY CALLS, content-digest warning hoặc graph-report omission trong qualification sau fix.

Quy trình

  1. Ghi commit/dirty state và tạo clean clone local tại đúng HEAD.
  2. Build bằng manylinux glibc 2.28 theo workflow, pin Ladybug/OpenSSL, audit ELF, package, smoke và tests.
  3. Chạy trực tiếp bin/cih cho native; build Dockerfile.portable từ cùng bundle cho OCI.
  4. Cold qualification dùng clean clone; ba warm call độc lập dùng cùng persistent source/data để xác minh cache. Docker dùng --network none.
  5. Serve/MCP được probe đủ health/ready/graph, initialize/tools/list và ba tool calls; Docker token và SIGTERM được kiểm tra.
  6. Chuẩn hóa path/timestamp rồi so counts, versions và SHA-256 JSONL.
Command chính xác (rút gọn biến đường dẫn)
# Native
CIH_HOME=$RUN/home cih index $RUN/repo --force --no-wiki --json
CIH_HOME=$RUN/home cih index $RUN/repo --no-wiki --json  # ×3
CIH_HOME=$RUN/home cih serve $RUN/repo --bind 127.0.0.1:$PORT

# Docker one-shot, mỗi clean run
docker run --rm --network none --user "$(id -u):$(id -g)" \
  -e HOME=/tmp/cih-user -e CIH_HOME=/data \
  -v "$RUN/repo:/repo" -v "$RUN/home:/data" IMAGE \
  index /repo --force --no-wiki --json
# Fresh second container, same mounts, ×3
docker run --rm --network none -v repo:/repo -v data:/data IMAGE \
  index /repo --no-wiki --json

# Docker serve
docker run -d -p 127.0.0.1::8080 --user "$(id -u):$(id -g)" \
  -e CIH_API_TOKEN=study-token -v "$RUN/repo:/repo" -v "$RUN/home:/data" \
  IMAGE serve /repo --bind 0.0.0.0:8080

Giới hạn nghiên cứu

  • n=3 đủ phát hiện regression lớn, không đủ mô tả tail latency; p95 = max.
  • Một máy, một CPU/kernel/storage; không pin CPU, không drop page cache và không chạy workload song song.
  • Process RSS và container cgroup peak có scope khác, vì vậy chỉ trình bày chứ không kết luận memory winner.
  • Docker readiness gồm client/create/start; native readiness chỉ từ lúc spawn process.
  • Image là local qualification build của working patch, chưa phải artifact release có chữ ký/provenance từ GitHub Actions.
  • Cold chỉ đo một lần sau fix; các số cold 3-run trong nghiên cứu gốc vẫn hữu ích nhưng không được trộn vào bảng regression này.
